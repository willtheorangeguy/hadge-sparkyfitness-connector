# Changelog

## 0.1.0

- Sync Hadge workout CSVs from a private GitHub repository to Sparky Fitness.
- Import history, update changed workouts, and poll automatically every five minutes.
- Preserve same-day workouts using complete daily batches and persistent accepted payloads.
- Use explicit diary timezones and whole-day date filters.
- Support file-based credentials, previews, authentication checks, and retry recovery.
- Include a real Sparky v1.8.0/PostgreSQL Docker acceptance suite.
- Publish amd64/arm64 images and downloadable Compose/environment setup files on releases.
